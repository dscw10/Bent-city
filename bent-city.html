Bend start — the life-size street ahead of you at a standstill.
Speed push — how much further out the bend start travels at full speed. 0 freezes the view; high values give you a long road when you're moving and a wide map when you're not.
Curl radius — how tightly the world folds up. Small = a sharp horizon.
Map scale — 1.00 is life size; drop it and the fold shrinks the world as it lifts, so the map covers far more ground.
Fold easing — 0.00 is a constant-radius arc, which reads as a chamfered edge. 1.00 eases curvature in and out from zero, like a clothoid on a motorway slip road.
Map flatten — how much building height survives onto the map. 0.00 lays them perfectly flat; nudge it up for a raised-relief look. Turn it to 0.60 to see the problem it solves.
Map falloff — compresses distance the higher up the map you go, so the far end of the route folds into finite screen height. 0.00 is a linear map.
Building height — global scale. Lower buildings mean less of the map hidden behind them.
Map lock — 0.00 turns the map with you. 1.00 world-locks it so north stays north and only the transition band twists. In between, the map swings lazily behind your turns.
Camera distance — pulls back and up along one diagonal.
